1.  **(254页) <span id="既非此处亦非彼处-欧洲漫游记-Bill-Bryson">[《既非此处亦非彼处：欧洲漫游记》(Neither Here nor There Travels in Europe) - Bill Bryson, 1991](https://stevenspage.github.io/english_ebooks/reader.html?book=./ebooks/Neither%20Here%20nor%20There%20Travels%20in%20Europe%20%28Bill%20Bryson%29.epub)</span>**  | ⭐Goodreads：3.85分 (7.9万人评分)
    <br>📖 **类型**：非虚构 · 幽默 · 回忆录 · 传记
